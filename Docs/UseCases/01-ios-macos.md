# Use Case 01 — 跨平台開發環境共享：iOS / macOS

## 問題背景

對於 iOS 開發者而言，穩定且相容的 macOS 與 Xcode 環境是重要的開發需求。

然而，部分開發者可能沒有長期可用的 Mac 設備，過去依賴 OpenCore Legacy Patcher、非官方 macOS 安裝方案，或受限的雲端 CI 服務進行開發與建構。

這些方案可能面臨硬體相容性、系統更新、執行穩定性或資源額度等限制。

## OpenBuildNet 如何解決這個問題？

透過 OpenBuildNet，擁有實體 Mac 設備的節點提供者，可以在自願授權及安全隔離的前提下，將閒置的 macOS 建構與測試能力共享至分散式網路。

需要 macOS 環境的開發者，可以提交符合條件的建構或測試任務，由網路中的可用節點協商承接。

實際應用包含以下項目。

- **程式碼建構**　使用 Xcode 編譯 iOS、macOS 專案。
- **錯誤檢查**　取得編譯錯誤、警告與診斷日誌。
- **自動化測試**　執行 XCTest、單元測試及支援的 UI 測試。
- **靜態分析**　執行 Xcode Analyzer，協助發現潛在問題。
- **相容性驗證**　在不同 Xcode、SDK 或目標平台環境下進行測試。
- **產物回傳**　取得建構產物、測試報告及診斷結果。

## 核心價值

OpenBuildNet 透過自治節點之間的資源協商，讓分散在不同開發者手中的設備形成可共享的建構、測試與驗證網路。開發者可以使用其他節點提供的硬體與開發環境，取得所需的特殊平台與工具鏈，並降低對單一 CI 供應商的依賴。

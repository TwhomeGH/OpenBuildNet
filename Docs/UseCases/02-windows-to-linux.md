# Use Case 02 — 跨平台開發環境共享：從 Windows 建構 Linux 應用

## 問題背景

開發者平常在 Windows 上編寫程式，但要交付在 Linux 上執行的命令列工具或後端服務。開發者手邊只有 Windows 電腦，而專案需要在 Linux 環境編譯、執行測試，或確認所用的系統函式庫能與部署環境相容。

## OpenBuildNet 如何解決這個問題？

開發者在 Windows 上提交原始碼快照、建構指令與環境需求。以 Linux x86-64 命令列工具為例，具備對應架構與工具鏈的授權節點可承接任務，在隔離環境中編譯與執行測試，再把退出碼、建構日誌和指定的執行檔回傳給 Windows 提交端。

- **程式碼建構**　使用 Linux 工具鏈編譯 CLI、後端服務或原生函式庫。
- **自動化測試**　在 Linux 上檢查路徑大小寫、檔案權限與程序行為。
- **相容性驗證**　依部署需求指定 CPU 架構與建構環境，檢查目標環境所需的函式庫。
- **產物回傳**　在 Windows 上查看 Linux 建構日誌並取得指定產物。

## 核心價值

開發者可以留在 Windows 的開發環境，使用經授權的 Linux 節點完成建構與測試。專案目前的實機驗收組合是 Windows 提交端加 Arch Linux 筆電，設定方式見 [Windows 操作 Arch Linux 建構節點指南](../WindowsArchSSH.md)。這組環境已完成雙向派工驗收。
